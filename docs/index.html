Shamba Direct API (1.0.0)

Download OpenAPI specification:

Shamba Direct is a REST API for a Kenyan farmer-to-buyer marketplace.

Try it out

  1. Start MySQL and load server/sql/schema.sql.
  2. Copy server/.env.example to server/.env and configure the database.
  3. Start the API with cd server && npm start.
  4. Use Try it out below. The GET examples use records from the configured development database; IDs can differ if your database has changed.

Data and write operations

/api/listings, /api/market-prices, /api/farmers/ratings, and /api/headquarters provide the partner-facing read endpoints. Other endpoints support the web app and include operations that create, change, or delete database records. Changes made with Try it out are permanent. Use a local or disposable database when testing write operations.

Authentication and privacy

The API does not currently require or issue authentication tokens. Login checks credentials but does not create a session. Do not use real passwords or personal information in Swagger UI examples. Do not expose this development API to the public internet.

Conventions

Request bodies use JSON. Most write fields use camelCase; /api/enquiries currently accepts product_id and buyer_id. Response fields generally use snake_case. Monetary and quantity values may be JSON numbers or decimal strings depending on the endpoint. Timestamps use ISO 8601.

Errors are JSON objects such as {"error":"Listing not found"}.
